# 🎀 TypoCute (Duolingo Edition - English Typing & Speaking Master)

Yeh application specially **Hindi-medium students aur ladkiyon** ke liye banayi gayi hai jo laptop par **English Typing** aur **English Vocabulary/Speaking** dono aasan, mazedaar aur cute tareeqe se seekhna chahte hain.

---

## 🌟 Main Highlights & Features:

1. **🎨 Cute Soft Claymorphism UI & Mascots:**
   - Soft pastel pink, mint aur gold duolingo-style theme.
   - Animated **Hello Kitty** aur **Mimi Rabbit** mascots jo har step par guide aur cheer karti hain.
   - 100% responsive full-page layout — koi vertical scrollbar nahi!

2. **🌸 Two Specialized Modes (2 Simplified Modes):**
   - **1. Chhote Shabd (Small Words Mode):**
     - 2,200+ curated, daily-use English words.
     - **100% Genuine, Accurate Hindi Meanings** (e.g. *asleep = सोया हुआ, accept = स्वीकार करना, bed = बिस्तर/पलंग, mother = माँ, smile = मुस्कुराना, cleverly = होशियारी से*).
     - 4 letter filters: *🎲 Sab Mixed, ⚡ Chhote (3-4 Letters), 🌟 Medium (5-6 Letters), 🏆 Bade (7+ Letters)*.
   - **2. 50-Word Paragraphs (बड़ा पैराग्राफ Mode):**
     - 30+ comprehensive 50-word stories with **100% complete, sentence-by-sentence accurate Hindi translations**.
     - *🎲 Agla Naya Essay (Random)* stream — bina repeat hue naye essays load hote hain.
     - **Background Auto-Generation:** Background mein naye topics par fresh 50-word essays auto-generate hote rehte hain taaki kabhi essays khatam na hon!

3. **🔁 Infinite Non-Repeating Progress:**
   - Jo bhi word ya paragraph complete hota hai, woh `localStorage` mein track hota hai.
   - Purana content kabhi repeat nahi hota jab tak poori library complete na ho jaye.

4. **🗣️ Natural Voice (Indian English Accent Support):**
   - In-built Web Speech API ke zariye har word aur paragraph ka clear pronunciation.
   - Automatic Indian English voice (`en-IN`) detection for natural local accent.

5. **⌨️ Color-Coded Virtual Laptop Keyboard & Finger Guides:**
   - Screen par keyboard dikhata hai ki kaun si ungli se kaun sa button press karna hai.
   - Home-row finger memory guide for fast touch typing without looking down.

6. **✨ AI Naye Shabd & AI Naya Essay (Hugging Face / Smart Generator):**
   - Kisi bhi topic par naye words ya 50-word essays generate karne ki suvidha (Online & 100% Offline smart fallback).

## 🚀 Windows 11 me Kaise Install Karein:

### 🌟 Sabse Best: `TypoCute_Windows11_Setup.exe` (Official Installer)
1. Bas **[`TypoCute_Windows11_Setup.exe`](TypoCute_Windows11_Setup.exe)** par double click karein!
2. Ek sunder Windows 11 setup wizard open hoga.
3. **"Install Now (अभी इनस्टॉल करें)"** par click karein:
   - Ye app ko laptop ke Programs folder me install karega.
   - **Desktop par cute icon banayega.**
   - **Windows 11 Start Menu** me add karega (Windows key dabakar "TypoCute" search karne par aayega).
   - **Windows 11 Settings > Apps (Installed Apps)** me officially register ho jayega!
4. Install hote hi app apne aap open ho jayegi!
